CHROMA — Multi-page creative-science playground

Included pages:
- index.html: home / room directory
- colour.html: interactive RGB colour mixer and palette relationships
- graphs.html: interactive sine graph and procedural colour field
- sound.html: waveform explorer and browser-generated tones
- objects.html: playful object/material study
- styles.css: shared visual system

Run:
1. Extract the ZIP.
2. Open index.html in a modern browser.
3. Use the top navigation to explore independent pages.

No build tools or JavaScript libraries are needed. Google Fonts require an internet connection; system font fallbacks are included. Sound starts only after clicking Play. Graph heatmap is synthetic illustration, not measured data. The car is a CSS illustration rather than a physically accurate 3D model.
